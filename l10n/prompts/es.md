# Español

Translate into Spanish, in a neutral international variety. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- Technical and plain, as Spanish software documentation is written: precise, with no emphasis the source does not have.
- Address the reader as "tú" wherever the English says "you"; elsewhere prefer impersonal forms ("se configura", "es posible").
- Headings take sentence case: a capital on the first word and on proper nouns only.
- Prefer vocabulary shared across Spanish-speaking countries over a word particular to one of them.

## Quotation marks

- A quoted phrase takes comillas angulares, «así», a quotation inside it takes “así”, and one inside that takes ‘así’.
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, as the glossary writes them, capital letter included, with these genders: el Aggregate, el Component, la Feature, la FeatureRecipe, la Recipe, el Manifest, la Release, el Provider, el Plugin, el Workload, la SchemaLibrary, la MappingLibrary, la ArtifactLibrary, la WorkloadLibrary.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: contrato social.
- `best practice`: buena práctica, the established Spanish term with the same force, las buenas prácticas; never "regla" or "obligación".
- `escape hatch`: vía de escape; never "resquicio" or "laguna", which read as a loophole.
- `convention`: convención; never "regla" or "norma".
- `unopinionated`: sin opiniones propias; "mathematically unopinionated" is "matemáticamente sin opiniones propias".
- `content-neutral`: neutral respecto al contenido.
- `agnostic to`: agnóstico respecto a, as in "agnóstico respecto a las convenciones".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
