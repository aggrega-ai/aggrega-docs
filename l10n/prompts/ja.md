# 日本語

Translate into Japanese. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- The polite です・ます form throughout, technical and plain, with no emphasis the source does not have.
- Do not address the reader as "あなた"; leave the subject out, as Japanese technical writing does.
- Use the terms established in Japanese software documentation (設定, コンパイラ, プラグイン).

## Quotation marks

- A quoted phrase takes 「このように」, and a quotation inside it takes 『このように』.
- Japanese text takes full-width punctuation (、。); inline code, a URL and an English term keep their own punctuation.
- Put a half-width space between Japanese text and a Latin-letter term or a number: Component を宣言します.
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, in Latin letters and as the glossary writes them, capital letter included; never translated, never written in katakana.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: 社会契約.
- `best practice`: ベストプラクティス; never "規則" or "必須".
- `escape hatch`: エスケープハッチ; never "抜け道", which reads as a loophole.
- `convention`: 慣例; never "規則" or "規約", which read as rules that are enforced.
- `unopinionated`: 主張を持たない; "mathematically unopinionated" is "数学的に主張を持たない".
- `mathematically blind`: 数学的に盲目; never "盲目的", which reads as reckless.
- `dumb`: 賢くない: it does what it is given and nothing more; never "単純", which softens it, nor "愚か", which insults.
- `blind to`: 〜が見えない, as in "慣例が見えない".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
