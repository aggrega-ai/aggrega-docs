# Malti

Translate into Maltese. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- Technical and plain, as Maltese software documentation is written: precise, with no emphasis the source does not have.
- Where the English says "you", prefer impersonal forms ("wieħed jista'", "għandu"); address the reader as "int" only where a sentence cannot do without it.
- Headings take sentence case: a capital on the first word and on proper nouns only.

## Quotation marks

- A quoted phrase takes “hekk”, and a quotation inside it takes ‘hekk’.
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, as the glossary writes them, capital letter included. The definite article stands before a kept term joined by its hyphen, assimilated as Maltese spelling requires before the term's first sound: il-Component, ir-Release, is-SchemaLibrary. The term itself never changes.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: kuntratt soċjali.
- `best practice`: l-aħjar prattika, l-aħjar prattiki; never "regola" or "rekwiżit".
- `escape hatch`: triq ta' ħruġ; never "lakuna", which reads as a loophole, nor "bieb ta' wara", which reads as a back door.
- `convention`: konvenzjoni, as in "konvenzjonijiet tal-ismijiet"; never "regola".
- `unopinionated`: mingħajr opinjoni tiegħu; "mathematically unopinionated" is "matematikament mingħajr opinjoni tiegħu".
- `content-neutral`: newtrali fir-rigward tal-kontenut.
- `agnostic to`: agnostiku fir-rigward ta', as in "agnostiku fir-rigward tal-konvenzjonijiet".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
