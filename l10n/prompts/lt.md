# Lietuvių

Translate into Lithuanian. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- Technical and plain, as Lithuanian software documentation is written: precise, with no emphasis the source does not have.
- Where the English says "you", prefer impersonal forms ("galima", "reikia"); address the reader as "jūs" only where a sentence cannot do without it.
- Headings take sentence case: a capital on the first word and on proper nouns only.

## Quotation marks

- A quoted phrase takes „taip“, and a quotation inside it takes ‚taip‘.
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, as the glossary writes them, capital letter included, never declined. Where the sentence needs a case ending, put a Lithuanian noun before the term and decline that noun: esybės Component, esybėje Release.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: visuomeninė sutartis.
- `best practice`: geroji praktika, gerosios praktikos; never "taisyklė" or "reikalavimas".
- `escape hatch`: atsarginis išėjimas; never "spraga", which reads as a loophole, nor "galinės durys", which reads as a back door.
- `convention`: konvencija, as in "pavadinimų konvencijos"; never "taisyklė".
- `unopinionated`: be savo nuomonės; "mathematically unopinionated" is "matematiškai be savo nuomonės".
- `content-neutral`: neutralus turinio atžvilgiu.
- `agnostic to`: agnostiškas … atžvilgiu, as in "agnostiškas konvencijų atžvilgiu".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
