# Română

Translate into Romanian. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- Technical and plain, as Romanian software documentation is written: precise, with no emphasis the source does not have.
- Where the English says "you", prefer impersonal forms ("se poate", "trebuie"); address the reader as "dumneavoastră" only where a sentence cannot do without it.
- Headings take sentence case: a capital on the first word and on proper nouns only.
- Write ș and ț with the comma below, never the cedilla.

## Quotation marks

- A quoted phrase takes „așa”, and a quotation inside it takes «așa».
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, as the glossary writes them, capital letter included, all neuter. The definite article and a case ending follow a kept term after a hyphen, so the term itself never changes: Component-ul, Release-ului, Feature-urile.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: contract social.
- `best practice`: bună practică, bunele practici; never "regulă" or "obligație".
- `escape hatch`: cale de ieșire; never "portiță", which reads as a loophole, nor "ușă din spate", which reads as a back door.
- `convention`: convenție, as in "convenții de denumire"; never "regulă" or "normă".
- `unopinionated`: fără opinii proprii; "mathematically unopinionated" is "matematic fără opinii proprii".
- `content-neutral`: neutru față de conținut.
- `agnostic to`: agnostic față de, as in "agnostic față de convenții".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
