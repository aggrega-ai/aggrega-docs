# Eesti

Translate into Estonian. Each choice below is a default, made without a native speaker's review, and a native speaker may change any of it.

## Register

- Technical and plain, as Estonian software documentation is written: precise, with no emphasis the source does not have.
- Where the English says "you", prefer impersonal forms ("saab", "tuleb"); use "teie" only where a sentence cannot do without it.
- Headings take sentence case: a capital on the first word and on proper nouns only.

## Quotation marks

- A quoted phrase takes „nii“, and a quotation inside it takes ‚nii‘.
- Inline code is never put in quotation marks: it keeps its backticks.

## English terms kept as they are

- The glossary's do-not-translate terms, as the glossary writes them, capital letter included, never given a case ending. Where the sentence needs one, join the term to an Estonian noun with a hyphen and give that noun the ending: Component-olemi, Release-olemis.
- A kept term's singular and plural are two distinct terms: `Component` and `Components`, `Release` and `Releases`. Write the form the source writes, a plural where the source has the plural and a singular where it has the singular, even where this language does not mark number.
- Everything in inline code, and every YAML key, CLI command and flag, entity kind and file path.
- The names of other products and standards: Kubernetes, Helm, Docker Compose, Terraform, CloudFormation, WebAssembly, JSON Schema, YAML, OCI.
- Abbreviations such as AOT, IR, CLI and ABI stay; their expansion is translated where the source spells it out.

## The qualifiers

- `social contract`: ühiskondlik leping.
- `best practice`: hea tava, head tavad; never "reegel" or "nõue".
- `escape hatch`: pääsetee; never "auk", which reads as a loophole, nor "tagauks", which reads as a back door.
- `convention`: konventsioon, as in "nimetamiskonventsioonid"; never "reegel".
- `unopinionated`: ilma oma arvamuseta; "mathematically unopinionated" is "matemaatiliselt ilma oma arvamuseta".
- `content-neutral`: sisu suhtes neutraalne.
- `agnostic to`: … suhtes agnostiline, as in "konventsioonide suhtes agnostiline".

A native speaker who finds a default here wrong corrects this file; every translation made after the correction follows it.
