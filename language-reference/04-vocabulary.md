# Vocabulary Overview

A small set of keywords recurs across Aggrega's entities. Rather than re-explaining them on every entity page, the Vocabulary chapters concentrate the teaching in one place per keyword family. Every entity that accepts one of these keywords does so with the same semantics this chapter set specifies.

The vocabulary falls into four families: the **topology triad** (`provides`, `inject`, `uses`) that wires explicit topological edges between nodes and carries the injection contract the compiler pipes through; the **data pillars** (`values`, `infra`, `parameters`, `locals`) that separate the four data concerns — developer intent, physical sizing, per-environment knobs, and private Recipe state; the **inheritance and interface** keywords (`extends`, `implements`) that compose catalog entities and bind Recipes to Components; and the **modifier system** (`appliesTo`, `appliesToAnyOf`) that governs which nodes a Feature attaches to via label selectors. Conceptual framing for how the pillars separate concerns lives in [../architecture/06-data-taxonomy-and-composition.md](../architecture/06-data-taxonomy-and-composition.md); topology resolution mechanics live in [../architecture/07-dependency-resolution.md](../architecture/07-dependency-resolution.md).

## Per-topic reference

- [Topology triad: `provides`, `inject`, `uses`](vocabulary/topology-triad.md) — the injection contract and the explicit topological-edge declarations. Covers compact vs. verbose inject syntax, the `.context.inject` / `.context.uses` pipe shapes templates read, and the dual-state context that protects Ops from nil-pointer panics.
- [Data pillars: `values`, `infra`, `parameters`, `locals`](vocabulary/data-pillars.md) — the four data pillars and their ownership. Developer-owned `values` and `parameters`, Ops-owned `infra`, Recipe-private `locals`, and the parameter-hoisting pattern for per-environment variation.
- [Inheritance and interface: `extends`, `implements`](vocabulary/inheritance-and-interface.md) — catalog-entity inheritance via `extends` (the YAML envelope deep-merge common to Components and Features, the data pillars an extending Component inherits from its base whole, and the JSON Schema 2020-12 composition a Feature's schema undergoes) and Recipe-to-Component binding via `implements` (exact, versioned-range, unversioned forms).
- [Modifier system: `appliesTo` and selectors](vocabulary/modifier-system.md) — Feature attachment selectors, the native Go label-matching engine, the string-form selector grammar, and the OR-composing `appliesToAnyOf` variant.
